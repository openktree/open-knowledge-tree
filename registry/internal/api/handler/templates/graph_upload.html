Upload a graph bundle (.json.gz) produced by an OKT export (either the Export to registry task or the Download button on a repo's graph page). The registry reads the bundle's metadata section to fill in the name, description, tags, and source/fact/concept counts automatically; the fields below override the bundle's metadata when filled in.

The upload streams the bundle to a temp file, then streams it to storage — memory use stays bounded even for 100s-of-GB bundles. A re-upload of the same bundle (matching name + sha256) refreshes the existing graph's metadata instead of creating a duplicate.
